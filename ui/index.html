Your recovery key

Write this down or store it in a password manager. It's the only way back in if you forget your password. It will not be shown again. It starts working when you click I've saved it, and any old key stops working then.

Set up a recovery key?

Your password can't be recovered. A recovery key is a one-time code that can unlock the vault and reset the password if you ever forget it. You can also do this later in Settings.
